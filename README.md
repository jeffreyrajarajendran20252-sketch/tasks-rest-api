# Tasks CRUD REST API (Django REST Framework)

A RESTful API with token-based user authentication (hashed passwords via PBKDF2) and protected CRUD endpoints for managing user-owned tasks.

## Tech Stack
- Python 3, Django, Django REST Framework (DRF), SQLite
